텍스트 전처리 설정

프리셋 적용과 세부 옵션 변경은 명시적인 버튼 동작으로만 반영됩니다.
1. 프리셋
프리셋을 고른 뒤 적용 범위를 선택합니다. 현재 옵션은 적용 버튼을 누르기 전까지 유지됩니다.
명시적 적용
프리셋을 선택하세요.
‘선택 항목 적용’은 아래 체크된 항목만 프리셋 값으로 덮어쓰고, 체크 해제 항목은 현재 옵션을 그대로 둡니다. ‘전체 적용’은 모든 전처리 옵션을 프리셋 값으로 바꿉니다.
부분 적용 항목체크된 항목만 덮어쓰기
2. 세부 옵션
현재 열람 중인 작품에 적용할 전처리 규칙을 직접 조정합니다.
광고·링크성 줄 제거
URL, 메신저 홍보, 배포 문구처럼 본문이 아닌 줄을 보수적으로 제거합니다.
장·화 제목 앞 여백 정리
프롤로그, 제1화 같은 제목 앞뒤 간격을 읽기 좋게 맞춥니다.
과도한 줄바꿈 보정
빈 줄이 지나치게 많을 때 최대 두 줄까지만 유지합니다.
붙어 있는 문장 사이 띄우기
마침표나 느낌표 뒤 공백이 전혀 없는 문장을 자연스럽게 띄웁니다.
대화문 기준 줄바꿈
따옴표 대화문이나 대사 시작 패턴이 길게 이어질 때 줄을 나눠 읽기 쉽게 정리합니다.
문단 밀도 자동 최적화
너무 빽빽한 긴 줄만 적당히 나누고, 과도하게 잘게 쪼개진 줄은 자연스럽게 이어 붙입니다.
후기·공지 제거 강화
작가 후기, 공지, 배포 관련 안내처럼 본문 외 요소를 더 강하게 걷어냅니다.
3. 미리보기
현재 chunk를 다시 불러와 전처리 결과 샘플과 적용 요약을 확인합니다.
