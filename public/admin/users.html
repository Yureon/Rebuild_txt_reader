사용자 관리

.env LOGINID / LOGINPW owner 전용 콘솔입니다. 사용자·가입코드·메타데이터 공급자와 운영 상태를 관리합니다.

사용자 생성

계정 기본값, 접근 폴더, 이동/삭제 권한을 한 패널에서 설정합니다.

메타데이터 권한을 켜면 탭과 작품 정보 수집 화면에 진입할 수 있습니다. 실제 적용·수집 변경은 전체 라이브러리 접근 권한이 있는 사용자만 가능합니다.

입력한 폴더와 하위 폴더만 이동할 수 있습니다.

삭제 권한은 별도로 부여합니다.

사용자 목록

계정 상태와 권한 요약을 가로형 행으로 확인합니다.

사용자 편집

선택한 계정의 접근 권한, 세션, 비밀번호, 독서 데이터를 조정합니다.

사용자 목록에서 편집할 계정을 선택하세요.

사용자

권한을 해제하면 서재의 메타데이터 링크와 작품 작업 버튼이 숨겨지고, 직접 URL과 API 접근도 차단됩니다.

소스 폴더와 하위 폴더에만 적용됩니다. 이동 대상은 해당 사용자의 라이브러리 접근 범위 안이어야 합니다.

삭제는 이동 권한과 별도로 확인합니다.

비밀번호 초기화

직접 입력 또는 임시 비밀번호 발급을 사용할 수 있습니다.

임시 비밀번호는 발급 응답에 한 번만 표시됩니다.

독서 데이터 관리

서버 저장 독서 데이터를 JSON으로 내보내거나 초기화합니다.

snapshot 목록을 불러오려면 사용자를 선택하세요.

위험 작업

세션 강제 만료, 독서 데이터 초기화, 계정 삭제는 운영 감사 로그에 기록됩니다. 삭제 확인 문구는 DELETE:<username> 형식입니다.

가입코드 발급

가입코드는 원문을 저장하지 않고 hash만 저장합니다. 발급 직후 표시되는 코드를 복사해 초대 대상자에게 전달하세요.

메타데이터 접근은 기본적으로 차단되며, 필요한 가입코드에만 명시적으로 허용합니다.

가입코드 목록

아직 발급된 코드가 없습니다.

감사 로그

최근 owner 작업과 인증/계정 작업 이력을 조회합니다. 민감 필드는 서버에서 redaction된 상태로 기록됩니다.

감사 로그를 조회하려면 이력 조회를 누르세요.

공통 언어팩 관리

owner가 저장한 언어팩은 모든 사용자의 사이트 언어 선택 목록에 표시됩니다. 같은 언어 코드의 사용자 정의 언어가 있으면 개인 문구가 공통 언어팩 위에 덮어씁니다.

한 줄에 원문=표시문구, 원문=>표시문구, tab 구분 또는 JSON 객체를 사용할 수 있습니다. HTML은 넣지 말고 표시할 텍스트만 입력하세요.

기본 메타데이터 공급자

내장 공급자의 활성화·우선순위·로그인 프로필을 관리합니다. 사이트 구조가 바뀌면 각 카드의 URL·selector override를 열어 직접 수정할 수 있습니다.

인증·네트워크 경계 Cookie 직접 입력은 사용하지 않습니다. 사용자 정의 URL은 자격 증명과 fragment가 없는 HTTPS 443만 허용하고, 저장된 host/path 범위 밖 요청은 차단합니다.

작품 묶음·대표 파일 검토

제목·작가·소개글·본문 sample 유사도와 회차·파일 품질을 함께 계산해 작품 묶음, 대표 파일, 검토 후보를 보여줍니다. 중복·이전본만 격리 스크립트 대상으로 선택할 수 있으며 브라우저에서는 파일을 직접 삭제하지 않습니다.

미리보기를 실행하면 유사도 근거, 대표 선정 이유와 검토 후보를 확인할 수 있습니다.
안전 실행 방식
  1. .\정리스크립트.ps1 -Library "실제 서재 경로"로 dry-run 결과를 검토합니다.
  2. 확인 후 -Apply를 추가하면 대상 파일을 라이브러리 내부 .txt-reader-cleanup/ 격리 폴더로 이동합니다.
  3. 생성 이후 크기·수정 시간이 달라졌거나 경로가 바뀐 파일, symlink, 대표 파일이 사라진 항목은 자동으로 건너뜁니다.
  4. 다른 판본과 의심 후보는 자동 격리하지 않습니다. 대표 지정·묶음 제외만 저장됩니다.

  4. 적용 결과는 대상 루트의 txt-reader-library-organization-result.json에 기록됩니다.
