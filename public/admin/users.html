사용자 관리

.env LOGINID / LOGINPW owner 전용 콘솔입니다. v417은 owner 콘솔 계정/audit/signup/state/permission wiring을 모듈로 분리하고, 운영 진단 결과를 요약 table/checklist table/finding card 구조와 warn/error 필터로 정리합니다. reader anchoring 계열은 변경하지 않았습니다.

사용자 생성

계정 기본값, 접근 폴더, 이동/삭제 권한을 한 패널에서 설정합니다.

꺼두면 해당 사용자의 검색 모달에서 전체검색 토글을 표시하지 않고, 서버 전체검색 요청도 차단합니다.

입력한 폴더와 하위 폴더만 이동할 수 있습니다.

삭제 권한은 별도로 부여합니다.

사용자 편집

선택한 계정의 접근 권한, 세션, 비밀번호, 독서 데이터를 조정합니다.

사용자 목록에서 편집할 계정을 선택하세요.

사용자

꺼두면 해당 사용자의 검색 모달에서 전체검색 토글을 표시하지 않고, 서버 전체검색 요청도 차단합니다.

소스 폴더와 하위 폴더에만 적용됩니다. 이동 대상은 해당 사용자의 라이브러리 접근 범위 안이어야 합니다.

삭제는 이동 권한과 별도로 확인합니다.

비밀번호 초기화

직접 입력 또는 임시 비밀번호 발급을 사용할 수 있습니다.

임시 비밀번호는 발급 응답에 한 번만 표시됩니다.

독서 데이터 관리

서버 저장 독서 데이터를 JSON으로 내보내거나 초기화합니다.

snapshot 목록을 불러오려면 사용자를 선택하세요.

위험 작업

세션 강제 만료, 독서 데이터 초기화, 계정 삭제는 운영 감사 로그에 기록됩니다. 삭제 확인 문구는 DELETE:<username> 형식입니다.

가입코드 발급

가입코드는 원문을 저장하지 않고 hash만 저장합니다. 발급 직후 표시되는 코드를 복사해 초대 대상자에게 전달하세요.

꺼두면 이 코드로 가입한 사용자의 검색 모달에서 전체검색 토글을 표시하지 않고, 서버 전체검색 요청도 차단합니다.

가입코드 목록

아직 발급된 코드가 없습니다.

감사 로그

최근 owner 작업과 인증/계정 작업 이력을 조회합니다. 민감 필드는 서버에서 redaction된 상태로 기록됩니다.

감사 로그를 조회하려면 이력 조회를 누르세요.

공통 언어팩 관리

owner가 저장한 언어팩은 모든 사용자의 사이트 언어 선택 목록에 표시됩니다. 같은 언어 코드의 사용자 정의 언어가 있으면 개인 문구가 공통 언어팩 위에 덮어씁니다.

한 줄에 원문=표시문구, 원문=>표시문구, tab 구분 또는 JSON 객체를 사용할 수 있습니다. HTML은 넣지 말고 표시할 텍스트만 입력하세요.
